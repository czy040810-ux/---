# 拾题微信小程序：导入与课堂发布指引

## 1. 当前交付范围

这是**原生微信小程序源码**，不是 H5 网页套壳。包括首页、登录注册、拍照上传、OCR 文本修正、个人错题、知识点筛选、复习反馈、公开共建题库与管理员审核。后端复用同级目录的 FastAPI + SQLite。所有主要代码有中文注释。

当前**未连接你的微信账号、未在微信开发者工具真机预览、未部署后端、未提交微信审核**，因此暂时不能提供全班扫码可用的小程序码。

## 2. 导入项目（无需 AppSecret）

1. 电脑安装微信开发者工具，登录你的小程序管理员/开发者微信。
2. 微信公众平台 `https://mp.weixin.qq.com` → 登录 → **开发管理 / 开发设置** → 查看 **AppID（小程序 ID）**。仅需复制 AppID，不要提供 AppSecret。
3. 用微信开发者工具“导入项目”，选择本 `miniprogram` 文件夹。
4. 将 `project.config.json` 中 `"appid":"touristappid"` 替换成自己的 AppID。
5. 将 `config.js` 中 `BASE_URL` 改为实际 HTTPS 后端地址，如 `https://api.你的域名.cn`，**不要改成 `localhost` 或 Streamlit 的 8501 地址**。
6. 在小程序管理后台配置 `request` 与 `uploadFile` 合法域名（通常是同一个后端 HTTPS 域名）。
7. 编译后按“拍题 → 我的错题 → 复习 → 投稿 → 管理员审核 → 公共题库”逐项检查。

## 3. 后端服务

项目根目录安装 `requirements.txt`，设置足够强的 `ADMIN_USER`/`ADMIN_PASSWORD` 后启动：

```bash
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

**面向全班使用时**，必须在你控制的云服务器或云应用平台上运行后端，通过 Nginx/Caddy 或平台网关提供稳定 HTTPS 域名，并为 SQLite 数据目录准备持久化磁盘、定期备份。公网后端的 `8000` 端口无需直接开放，推荐由 HTTPS 反向代理访问。正式使用前必须新增 IP/账号限流、文件访问归属校验、上传大小与总存储配额、登录错误次数限制、日志和监控。

此前的 Cloudflare 临时隧道地址每次重启都可能变化，**不适合作为小程序合法域名和课堂正式入口**。

## 4. 微信平台流程

- **开发者预览**：提供给管理员和开发人员测试。
- **体验版**：可以邀请符合微信平台条件的体验成员；不能把“体验版二维码”当作不受限制的全班开放方式。
- **正式版**：按微信当前要求完成必要备案、业务类目及隐私保护配置，上传代码并提交审核，通过且发布后，再使用正式小程序码供全班扫描。

平台政策、账号主体和域名限制会变化，以微信公众平台当前提示为准。

## 5. 课堂演示清单

1. 手机 A 注册并保存手写错题。
2. 手机 B 登录另一个账号，确认无法看到 A 的私有内容。
3. A 点击记住/未记住，检查下次复习日期变化。
4. A 申请公开，审核前手机 B 的公共库仍看不到。
5. 管理员审核通过，手机 B 刷新公共库可查看。
6. 提交包含“付费教辅原题”字样的示例，确认自动驳回。
7. 同时用 10～30 台手机进行压力/连通测试，记录成功率、响应时间和失败原因；此前没有此类实测结果。

## 6. 上线之前需要特别检查

- 登录方式为用户名/密码；密码不存明文，但课堂公网使用仍需限流、防撞库和安全评估。
- 微信端并未接入微信授权登录，不需要 AppSecret。
- OCR 需要 Tesseract 中文语言包；模型分析默认模拟模式，若接入真实模型需在服务端配置，不得放入 `config.js`。
- 当前版权规则只能拦截明显信号，管理员仍要人工审核，并明确用户投稿授权规则。
- 需要补充《隐私政策》与数据删除机制，真实用户数据不得用于未获授权的演示。
